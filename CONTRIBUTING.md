# How to contribute

Thanks for helping make this course clearer and more useful.

1. Pick one topic or issue.
2. Explain the problem the topic solves.
3. Add a small example before the code.
4. Keep C examples beginner-readable and compile with a C11 compiler.
5. Include expected output and complexity where relevant.
6. Test normal input, boundary cases, and invalid input.
7. Keep the `WHY?`, `THINK`, and `☕ BREAK` sections short.

Please do not submit copied solutions without understanding or attribution. Prefer clear explanations over clever code.
